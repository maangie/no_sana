# Takaichi → Cat (Chrome拡張)

高市早苗氏の画像を猫の画像に置き換えます。

## インストール
1. このフォルダをPCに保存
2. Chromeで `chrome://extensions` を開く
3. 右上「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

## 仕組み
顔認識ではなく、画像の alt / title / src / キャプション等のテキストに
「Takaichi」「高市」が含まれるかで判定しています。
猫画像は https://cataas.com から取得します。

## カスタマイズ
- `content.js` の `KEYWORDS` を編集すると判定語を変更できます。
  「高市郡」などの地名まで猫になるのが困る場合は最後の `/高市/` を削除してください。
